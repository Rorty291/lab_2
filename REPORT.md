## 2. Відповідь на контрольне запитання

**Запитання:** `Як викликати функцію в Python?`

**Відповідь:**

Функції у мові `Python` викликаються при використанні назви цієї функції та параметрів які обов'язкові для виконання сказаної функції.

Приклад викликання функції без параметрів:
```python
main()
```

Приклад викликання функції з параметрами
```python
a = 5
b = 10

main(a: int, b: int)
```
